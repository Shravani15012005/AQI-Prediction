# Air Quality Index (AQI) Prediction

# Description
The **Air Quality Index (AQI) Prediction** project focuses on analyzing air pollution data and understanding how different pollutants affect air quality. Using Python and data visualization techniques, the project explores pollutant concentrations, identifies patterns in air quality data, and uses machine learning to predict the Air Quality Index (AQI).
The project helps demonstrate how data analysis and machine learning can be used to understand environmental pollution and support better decision-making.

# Tech Stack
Programming Language: Python
Libraries: Pandas, NumPy, Matplotlib, Seaborn
Environment: Jupyter Notebook

# Dataset
The project uses air quality data containing pollutant measurements and AQI values.

The dataset includes air pollution measurements such as:
- PM2.5 and PM10
- Carbon Monoxide (CO)
- Nitrogen Dioxide (NO₂)
- Sulphur Dioxide (SO₂)
- Ozone (O₃)
- Air Quality Index (AQI)

# Goal
Analyze air quality data to understand pollution patterns.
Explore the relationship between different pollutants and AQI.
Visualize pollutant concentrations using graphs and charts.
Build a machine learning model to predict AQI based on the available data.

# Key Highlights
Data Analysis: Explore the dataset and understand pollutant distributions.
Data Visualization: Use scatter plots, line plots, and other visualizations to identify patterns and relationships between pollutants and AQI.
Pollutant Analysis: Investigate how pollutants such as CO and other particulate or gaseous pollutants relate to air quality.
AQI Prediction: Apply machine learning techniques to estimate AQI from the selected input features.
